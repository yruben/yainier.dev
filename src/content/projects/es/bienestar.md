# Plataforma Bienestar

La Plataforma Bienestar es una solución web integral diseñada para permitir la interoperatividad entre todos los registros públicos del país. Su objetivo principal es centralizar y facilitar el acceso a la información gubernamental de manera segura y eficiente.

**Servidor de Firma Web:**
Como parte fundamental de este ecosistema, se desarrolló un servidor de firma web robusto que permite:
*   **Firma Electrónica:** Autenticación y firma de documentos mediante certificados digitales.
*   **Protección por Cifrado:** Aseguramiento de la integridad y confidencialidad de la información.
*   **Compatibilidad Total:** Soporte para certificados gestionados por cualquiera de las infraestructuras de Llave Pública (PKI) existentes en Cuba.

**Modelo SaaS:**
La plataforma funciona bajo un modelo de Software como Servicio (SaaS), siendo utilizada actualmente por varios ministerios cubanos, incluyendo el **Ministerio de Comunicaciones**. Esta arquitectura permite una implementación rápida y una gestión centralizada de los servicios de identidad y firma.
