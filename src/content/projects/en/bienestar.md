# Bienestar Platform

The Bienestar Platform is an integrated web solution designed to enable interoperability between all national public registries. Its primary goal is to centralize and facilitate access to government information securely and efficiently.

**Web Signature Server:**
As a fundamental part of this ecosystem, a robust web signature server was developed, enabling:
*   **Electronic Signature:** Authentication and signing of documents using digital certificates.
*   **Encryption Protection:** Ensuring the integrity and confidentiality of information.
*   **Full Compatibility:** Support for certificates managed by any of the existing Public Key Infrastructures (PKI) in Cuba.

**SaaS Model:**
The platform operates under a Software as a Service (SaaS) model and is currently used by several Cuban ministries, including the **Ministry of Communications**. This architecture allows for rapid deployment and centralized management of identity and signature services.
