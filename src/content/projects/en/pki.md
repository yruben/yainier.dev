# Public Key Infrastructure (PKI)

A Public Key Infrastructure (PKI) is a set of hardware, software, policies, and standards needed to create, manage, distribute, use, store, and revoke digital certificates. In this project, a robust solution based on **EJBCA** was implemented to provide critical security services.

**Key Capabilities:**
*   **Certificate Issuance:** Generation of digital certificates for individuals, software components, and devices.
*   **Lifecycle Management:** Full control from initial request to renewal or revocation.
*   **Digital Signature and Encryption:** Enabling legally binding electronic signatures and protecting data confidentiality.
*   **Robust Authentication:** Secure access to systems using client certificates.

**Registration Interface:**
The main registration component allows users to manage their requests intuitively and securely.
