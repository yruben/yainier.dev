# IDE_BRAND_KIT

Kit de marca audiovisual del canal de YouTube **Ingeniero de Éxito (IDE)**.

Es la fuente de verdad del estilo del canal: cada video se planifica, monta y revisa contra estos documentos.

| Archivo | Contenido |
| --- | --- |
| `brand_guidelines.md` | Identidad del canal, audiencia, logotipo y control editorial |
| `editing_style.md` | Filosofía de montaje, ritmo y flujo de producción |
| `storytelling_guidelines.md` | Estructura narrativa y reglas de autenticidad |
| `color_palette.json` | Paleta corporativa y criterios de color |
| `typography.md` | Tipografías y reglas de texto en pantalla |
| `motion_graphics.md` | Catálogo de piezas gráficas reutilizables |
| `audio_profile.md` | Cadena de voz, música y objetivos de mezcla |
| `broll_guidelines.md` | Selección de B-Roll y control de licencias |
| `style_log.md` | Registro de observaciones y preferencias por video |
| `templates/` | Plantillas de trabajo (plan de edición, registro de B-Roll, QC, notas) |

## Cómo se mantiene

- Las reglas de este kit son **permanentes**: no se cambian por una observación aislada.
- Después de cada video, las observaciones se anotan en `style_log.md` y se clasifican como permanentes, específicas del video o experimentos pendientes de aprobación.
- Una preferencia pasa a los documentos del kit solo cuando el responsable del canal la aprueba como permanente.
- Lo marcado como **PROPUESTA** todavía no está aprobado: es un punto de partida a confirmar.
